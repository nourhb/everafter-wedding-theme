# Ever After — Wedding Planner Block Theme

**Ever After** is a romantic, elegant WordPress block theme built for wedding planners, venues and bridal studios. Soft ivory and blush tones, champagne gold accents, Cormorant Garamond serif typography and photo-rich patterns — a theme that feels like a luxury wedding editorial.

## Features

- **Full Site Editing** — edit headers, footers, templates and every pixel with the block editor
- **Complete theme.json design system** — ivory/blush/champagne-gold/espresso palette, Cormorant Garamond + Jost type, fluid type scale, soft shadows
- **10 hand-built block patterns** — hero, about, services, stats, gallery, pricing packages, process timeline, testimonials, FAQ, booking CTA
- **"Midnight" style variation** — one-click moody dark romantic mode
- **Photo-rich by default** — real wedding photography wired into hero, gallery, testimonials and CTA patterns
- **Motion with manners** — soft scroll reveals, animated counters, back-to-top button; all disabled under `prefers-reduced-motion`
- **Accessibility** — skip link, visible focus states, semantic landmarks, keyboard-friendly navigation
- **Translation-ready** — `everafter` text domain

## Installation

1. Download or clone this repository.
2. Copy the `everafter-wedding-theme` folder into `wp-content/themes/` (rename the folder to `everafter` if you like).
3. In WordPress, go to **Appearance → Themes** and activate **Ever After**.
4. Open **Appearance → Editor** to customize templates, or insert any **Ever After** pattern from the block inserter.

No plugins required. Google Fonts (Cormorant Garamond + Jost) load automatically; the theme works offline with system fallbacks.

## Customization

- **Colors & fonts:** everything flows from `theme.json` — tweak the palette, type scale or spacing there.
- **Style variation:** switch to the **Midnight** dark romantic style from the Site Editor's Styles panel.
- **Custom page template:** `page-wide.html` (1200px canvas) is registered as a page template.
- **Block styles:** Outline Gold (button), Soft Card (group), Arched Frame (image), Script Accent (heading).
- **Front-end script:** `assets/js/theme.js` handles scroll reveals, stat counters and the back-to-top button — vanilla JS, no dependencies.
